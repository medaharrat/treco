# Contact & Support

Treco is a free, open-source project maintained by an individual developer — there's no support team, company, or
dedicated email inbox behind it. The project's public GitHub repository is the official contact and support
channel.

## GitHub (official channel)

For bug reports, provider-compatibility issues, and feature requests, open an issue directly:

**[github.com/medaharrat/treco/issues](https://github.com/medaharrat/treco/issues)**

## Security or privacy reports

For anything sensitive — a suspected security or privacy issue you'd rather not post publicly — use GitHub's private
vulnerability reporting on the repository instead of a public issue:

**[github.com/medaharrat/treco/security/advisories/new](https://github.com/medaharrat/treco/security/advisories/new)**

See [SECURITY.md](https://github.com/medaharrat/treco/blob/main/SECURITY.md) in the repository for what a good
report should include.

## What you can reach out about

- **Privacy or security questions** — anything about what Treco does or doesn't access, or a suspected security
  issue. See the [Privacy Policy](privacy-policy.md) for the full detail first.
- **Bug reports** — something in the dashboard, popup, or a calculation looks wrong.
- **Provider compatibility issues** — a supported AI site changed its page and Treco stopped detecting usage
  correctly, or you'd like a new provider supported.
- **Feedback and feature requests** — what would make Treco more useful to you.

## Response times

Treco is developed and maintained in personal time by a single developer, so please allow reasonable time for a
response. Security-sensitive reports will be prioritized where possible.
